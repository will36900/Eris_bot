# Hermes 更新与 QQ 补丁

本项目在 Hermes Agent v0.23.0 上使用了一组 QQ 兼容补丁。补丁的公开源码和测试见 [Hermes fork 的固定提交](https://github.com/will36900/hermes-agent/commit/c85aa7e7d6)。它不是 Hermes 上游的正式功能，后续上游版本可能已包含同等实现，也可能需要重新适配。

补丁包括：

- 共享群会话按 `group_member_names` 标注发言者；优先匹配完整成员 ID，其次匹配前 8 位，未配置时使用前 8 位作为回退。成员 ID 和昵称只保存在使用者本机。
- 群图片发送保留回复关联，便于 QQ 将图片作为对消息的回复处理。
- QQ 无法直接抓取图片或语音 URL 时，先使用 Hermes 的媒体下载检查与缓存，再尝试本地上传。

## 更新时

`hermes update` 可能切换到上游发布版本，或重建运行环境；`hermes pm repair` 也可能重建环境。因此旧版本已应用补丁，并不代表更新后仍会生效。先保存自己的配置与源码改动，再对照固定提交检查新版本的实际实现；代码结构发生变化时，应结合新版实现迁移，而不是直接套用旧补丁。

确认测试通过后，重启 gateway 让新代码加载。然后在自己的测试群中确认：

1. 两位成员的消息分别显示正确的 `[名称]`；未配置成员按预期回退。
2. 发送图片时回复关联正常；QQ 无法抓取媒体地址时，本地回退上传正常。
3. 已确认 gateway 实际加载的是修改后的代码；若环境重建，重新检查。

不要将真实群号、成员 ID、昵称对照表、凭据或运行日志提交到公开仓库。发布前请阅读 [安全约定](../SECURITY.md)。
